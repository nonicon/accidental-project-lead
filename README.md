One line, 200 characters at most: a joke about office life, written by a small deterministic Python program to `/output/entry.txt` for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty ($2 in USDC).

## The joke

> I replied "sounds good" to a 47-email thread and somehow ended up leading the project.

## Run it

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
